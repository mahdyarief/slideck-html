LANGKAH 1 DARI 4 Pasang sekali, lalu mulai deck di foldernya sendiri
01

Pasang perintahnya

npm install -g slideck-html
02

Buat deck

slideck init my-deck && cd my-deck
03

Lihat hasilnya

deck.json, folder slides/ berisi dua contoh slide, dan .gitignore.

Butuh: Node.js 18 atau lebih baru. Ekspor PDF, PowerPoint dan pengecekan juga butuh Chrome, Edge atau Chromium.
