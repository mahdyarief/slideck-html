STEP 1 OF 4 Install once, then start a deck in its own folder
01

Install the command

npm install -g slideck-html
02

Create a deck

slideck init my-deck && cd my-deck
03

See what you got

deck.json, a slides/ folder with two sample slides, and a .gitignore.

Needs: Node.js 18 or newer. PDF, PowerPoint export and the check also need Chrome, Edge or Chromium.
